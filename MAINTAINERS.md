# Ferqon Firmware Maintainers

Ferqon firmware is maintained by the Revyr Labs team and community contributors.

## Current Maintainers

| Name | Role | GitHub | Contact |
|------|------|--------|---------|
| Revyr Labs | Core maintainer | [@revyrlabs](https://github.com/revyrlabs) | [support@revyrlabs.com](mailto:support@revyrlabs.com) |

> **Note:** Individual maintainer GitHub handles should be added here as
> they are confirmed for public attribution. The organization account
> is listed as the initial maintainer.

## Responsibilities

- Reviewing and merging pull requests
- Triaging issues and prioritizing the roadmap
- Keeping the build green across the supported PlatformIO environments
- Updating generated headers and documentation when `board.yml` changes

## How to Reach Us

- Open an issue or pull request on GitHub: https://github.com/revyrlabs/Ferqon-Firmware
- For security concerns, please see [SECURITY.md](SECURITY.md)

## Becoming a Maintainer

Contributors who make sustained, high-quality contributions may be invited to
take on maintainer responsibilities. See [CONTRIBUTING.md](CONTRIBUTING.md) for
guidelines on how to contribute.
